## Change control

### Purpose
- What changes and why?

### Scope
- Repository:
- Branch:
- Production impact: none / possible / direct

### Verification
- [ ] Tests/checks run
- [ ] Security impact reviewed
- [ ] Secrets not introduced
- [ ] Dependency impact reviewed
- [ ] Deployment/runtime evidence identified where applicable

### Compliance
- [ ] No protected control bypass
- [ ] No destructive action without authorization
- [ ] Evidence/rollback path documented
